# pipegrid

Pipe digests and grid fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/pipegrid/

## Install / run

```bash
git clone https://github.com/theworker02/pipegrid.git
cd pipegrid
node src/cli.js
node --test
```
